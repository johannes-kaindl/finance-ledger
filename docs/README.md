# Finance Ledger — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning something and fixing something are different needs, so they live on different pages. Only the kinds that have content are listed here.

**New here?** → [Getting started](getting-started.md) — from the install to your first balance overview.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the exact message you see, what it means, what to do.

| | |
|---|---|
| **[Getting started](getting-started.md)** | Learning-oriented. Point the plugin at a finance folder, rebuild the journal from CSVs, read the dashboard. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "Could not find journal.ledger", "No CSVs found", "Re-import failed". |
| **[Design system](design.md)** | Explanation and reference. The `--fl-*` tokens, the KSP palette and where they are wired. |
| **[UI cookbook](UI-Cookbook.md)** | Reference for people who build views: patterns, classes and tokens. |

The [README](https://github.com/johannes-kaindl/finance-ledger/blob/main/README.md) covers what the plugin does, how to install it, every setting and the note schema.
